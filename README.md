# 🦠 COVID-19 Data Analysis Project

## 📌 Project Overview
This project analyzes COVID-19 data to understand the spread, impact, and recovery trends across different countries/regions. It involves data cleaning, transformation, and visualization to extract meaningful insights.


## 🎯 Objective
- Analyze COVID-19 cases, deaths, and recoveries
- Calculate important metrics like death rate and recovery rate
- Identify trends and patterns in the data
- Visualize data for better understanding


## 🛠️ Tools & Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib


## 📂 Dataset Description
The dataset includes the following key columns:
- Country / Region
- Confirmed Cases
- Deaths
- Recovered Cases


## 🧹 Data Cleaning & Preparation
- Replaced zero values in cases to avoid division errors
- Created new columns:
  - **Death Rate** = Deaths / Cases
  - **Recovery Rate** = Recovered / Cases
- Converted metrics into percentages for better visualization


## 📈 Data Analysis & Visualization
The project includes:
- Bar charts showing country-wise comparisons
- Line graphs for trend analysis
- Analysis of highest and lowest affected regions
- Visual representation of death and recovery rates


## 🔍 Key Insights
- Countries with high confirmed cases also show varying recovery rates
- Some regions have high death rates indicating healthcare challenges
- Recovery trends improve over time in many regions
- Significant differences observed across countries


## ✅ Conclusion
The analysis provides a clear understanding of COVID-19 trends and highlights the importance of data-driven decision-making in public health.
